# 간편출력 (EasyPrint)

**프린터 기본 설정을 바꾸지 않고**, 저장해 둔 형식(A4 세로 컬러 / A3 가로 컬러 / 편지봉투 …)으로 바로 출력하는 Windows 프로그램입니다.

> 편지봉투를 한 번 찍으려고 프린터 설정을 바꿨다가, 다음 A4 출력이 봉투 설정으로 나가는 문제를 없애기 위해 만들었습니다.

## 사용 방법

1. **파일 선택** – `파일 추가...` 또는 탐색기에서 파일 우클릭 → `보내기` → `간편출력`
2. **프린터 선택** – 목록에서 선택 (`Windows 기본 프린터`를 고르면 그때그때의 기본 프린터 사용)
3. **출력 방식 선택** – 위쪽 **저장된 출력 형식** 버튼을 누르면 즉시 적용
   - 기본 제공: `A4 세로 컬러`, `A3 가로 컬러`, `편지봉투`
   - 용지 · 방향 · 컬러/흑백 · 급지함(수동 급지 등) · 양면 · 크기(맞춤/100%) · 매수 조절 가능
4. **출력** – 선택한 설정은 **이번 출력에만** 적용됩니다. 프린터의 '인쇄 기본 설정'은 그대로입니다.
5. **형식 저장** – `새 형식으로 저장`(예: "회의자료 A3 흑백"), `현재 형식에 덮어쓰기`, `이름 변경`, `◀ ▶`(순서), `삭제`

설정 파일 위치: `%APPDATA%\EasyPrint\presets.json`

### 편지봉투

기본 `편지봉투` 형식은 사무실에서 실제로 쓰던 설정으로 들어 있습니다.

| 항목 | 값 |
|---|---|
| 용지 | 사용자 지정 **115 × 216 mm** |
| 급지함 | **다목적 용지함** |
| 방향 | 세로 |
| 색상 | 컬러 |
| 양면 | 단면 |

- 급지함 이름은 프린터마다 다릅니다(`다목적 트레이`, `MP 용지함`, `Manual Feed`, `수동 급지` 등). 비슷한 이름을 자동으로 찾습니다. 다른 급지함이 잡혔다면 직접 고른 뒤 `현재 형식에 덮어쓰기`를 누르세요.
- 프린터에 115 × 216 크기 용지가 이미 등록돼 있으면 그 용지로, 없으면 사용자 지정 크기로 보냅니다. 드라이버가 크기를 바꾸면 출력 후 알려 줍니다.

## 지원 파일

| 형식 | 처리 방식 |
|---|---|
| PDF | 바로 출력 |
| 이미지 (png, jpg, bmp, gif, tif 다중 페이지, webp) | 바로 출력 |
| 한글 (hwp, hwpx) | 설치된 **한컴오피스 한글**로 PDF 변환 후 출력 |
| 워드 / 엑셀 / 파워포인트 | 설치된 **MS Office**로 PDF 변환 후 출력 |

- 한글 변환 시 "파일 접근 허용" 보안 창이 뜰 수 있습니다 → `모두 허용`을 누르세요.
- 엑셀은 각 시트의 인쇄 영역/페이지 설정대로 PDF가 만들어집니다.

## 설치 · 자동 업데이트

### 처음 한 번만
1. [Releases 최신 버전](https://github.com/godtaeho/claude/releases/latest)에서 `EasyPrint.exe` 내려받기 (로그인 불필요)
2. 실행하면 자동으로 **설치**됩니다
   - 설치 위치: `%LOCALAPPDATA%\Programs\EasyPrint\EasyPrint.exe` (관리자 권한 불필요)
   - **바탕화면**과 **시작 메뉴**에 `간편출력` 바로가기 생성
   - 내려받은 파일은 지워도 됩니다
3. 오른쪽 아래 `탐색기 '보내기' 메뉴에 등록`을 누르면 파일 우클릭 메뉴에서 바로 보낼 수 있습니다

> Windows SmartScreen이 "알 수 없는 게시자"라고 경고하면 `추가 정보 → 실행`을 누르세요. (서명하지 않은 사내용 프로그램이라 처음 한 번 나옵니다)

### 그다음부터는 자동
- 프로그램을 켤 때(켜 둔 상태라면 6시간마다) 새 버전을 확인합니다.
- 새 버전이 있으면 **뒤에서 조용히 내려받아 SHA-256으로 검증한 뒤 설치**합니다. 출력 중이어도 방해하지 않습니다.
- 설치가 끝나면 아래쪽에 `✔ vX.Y.Z 설치 완료`가 표시됩니다. **다음 실행부터 새 버전**이 적용되고, `새 버전으로 다시 시작`을 누르면 바로 적용됩니다.
- 끄고 싶으면 아래쪽 `자동 업데이트` 체크를 해제하세요. `지금 확인`으로 직접 확인할 수도 있습니다.

### 새 버전 배포하는 법 (개발자용)
`easyprint/__init__.py`의 `__version__`을 올려서 푸시하면 끝입니다. GitHub Actions가 Windows에서 테스트 → exe 빌드 → **릴리스 생성**까지 자동으로 하고, 사용자 PC들은 다음 실행 때 자동으로 업데이트됩니다. 버전을 올리지 않은 푸시는 배포되지 않습니다.

### 파이썬으로 직접 실행 (개발용)
```bat
pip install -r requirements.txt
pythonw main.py
```
(이 경우 자동 설치/업데이트는 동작하지 않습니다)

## 동작 원리 (왜 기본 설정이 안 바뀌나)

Windows가 권장하는 방식([DocumentProperties](https://learn.microsoft.com/windows/win32/printdocs/documentproperties))을 그대로 사용합니다.

1. 프린터의 현재 설정(DEVMODE)을 **복사**해 옵니다.
2. 복사본에서 용지·방향·컬러·급지함·양면만 바꾸고, 프린터 드라이버에게 검증시킵니다.
3. 그 설정으로 이번 인쇄 작업 하나만 만듭니다.

`SetPrinter`(기본 설정 저장)나 기본 프린터 변경은 전혀 호출하지 않습니다.
자동 테스트에서 `Microsoft Print to PDF`로 A3 가로 / A4 세로 / 봉투 DL을 출력한 뒤, 결과 용지 크기가 맞는지와 프린터 기본 설정이 그대로인지를 확인합니다.

## 참고 / 한계

- 페이지를 프린터 해상도(최대 300dpi)의 이미지로 그려서 보냅니다. 일반 문서·봉투 주소 출력 품질에는 문제없지만, 아주 큰 문서는 스풀 용량이 커질 수 있습니다.
- `사용자 지정 크기`는 프린터 드라이버가 지원해야 적용됩니다. 지원하지 않으면 출력 후 경고가 표시됩니다.
- 드라이버가 용지 설정을 다른 값으로 바꾸면 출력 완료 창에 알려 줍니다.

## 개발

```bash
pip install -r requirements-dev.txt
python -m pytest            # Windows 가 아니면 가상 프린터로 테스트
EASYPRINT_FAKE=1 python main.py   # 가상 프린터로 화면 확인 (결과는 fake_print_output/*.png)
```

구성: `easyprint/presets.py`(형식 저장) · `layout.py`(배치 계산) · `documents.py`(파일→페이지) · `engine.py`(출력 흐름) · `winprint.py`(Win32 인쇄) · `app.py`(화면)
